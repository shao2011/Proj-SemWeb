Books Linked Data (Goodreads Best Books Ever, top 10,000)

Books, editions, contributors, series, awards, characters and settings of the 10,000 most-rated books of the Goodreads Best Books Ever list, linked to Wikidata, DBpedia and Open Library.

  • Ontology: HTML · Turtle
  • Dataset description (VoID): HTML · Turtle
  • SPARQL endpoint: http://localhost:3030/books/sparql (Apache Jena Fuseki; it runs on our machine, see the README)
  • Source code and documentation: https://github.com/shao2011/Proj-SemWeb
  • Licence: CC BY-NC 4.0, derived from the Best Books Ever dataset (Zenodo)

Data dumps

GitHub release data-v1, one file per named graph:
